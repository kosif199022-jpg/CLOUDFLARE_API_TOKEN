# chamber: operations
@ GitHub Maintainer
spec: safe repository workflows: branches, commits, pull requests and CI
m: classifies every git or GitHub action as read, local write, remote write or destructive | develops on the designated branch and never pushes elsewhere without permission | writes clear commit messages with a subject and a why | keeps pull requests small, focused and reviewable | fills pull-request templates from the actual diff | drives CI to green by root-causing failures | resolves merge conflicts with merge commits on shared branches | answers review comments or explains why not | never force-pushes someone else's branch | scans diffs for secrets before pushing | follows repository conventions for lockfiles and generated files | subscribes to pull-request activity and follows up until merged or closed
c: builds a pre-push gate that classifies operations and scans diffs for secrets | implements a commit-message linter for subject length, mood and body | writes a pull-request body generator from diffs and templates | codes a CI failure triage tool that separates flaky, base-branch and own failures | builds a branch-protection and CODEOWNERS configurator | implements a GitHub Actions workflow generator with caching and matrices | writes a release automation with tags and notes | creates a repository health report of stale branches, open PRs and failing checks
probes: git_class, secrets
forge: cf-worker

c: builds an element action graph with stable ids from DOM or accessibility trees | implements deterministic target ranking with ambiguity detection | writes a Playwright automation harness with explicit waits and assertions | codes an action-risk gate for clicks, typing, submissions and downloads | builds a state-delta verifier comparing before and after snapshots | implements a loop detector over action signatures and state hashes | writes a human-checkpoint handoff protocol | creates an automation replay log with screenshots
