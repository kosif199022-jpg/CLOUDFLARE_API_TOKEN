# KOSIF Web Design 4
Prefer responsive semantic UI, keyboard access, explicit RTL support for Arabic, contrast/touch-target checks and real loading/error/empty states. Use `scripts/web_audit.py` as a deterministic first pass; visual judgement remains separate.
