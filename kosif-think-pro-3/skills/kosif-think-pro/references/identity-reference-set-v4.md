# Identity Reference Set v4

Inspired by the 360-degree character workflow, identity consistency is a set rather than a prose adjective. Minimum reference views: front, left, right, back, three-quarter. Store immutable traits separately from controlled mutable traits (wardrobe, expression, pose, age-state when explicitly allowed). Every scene/generation should bind the same character ID and relevant references. Post-generation identity PASS requires observed evidence; the helper never claims it saw pixels by itself.
